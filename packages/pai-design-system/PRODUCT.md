# PAI Universe — Product Definition

## Vision
The Pi-powered agent economy workspace. Seven protocols under one signed universe. Identity, memory, labor, trust — each a protocol, each a subdomain, all anchored to `axiomid.app` via TrustChain.

## Core Protocols (The Seven)
| Protocol | Subdomain | Purpose |
|----------|-----------|---------|
| **AIP** | `aip.axiomid.app` | DID documents, verifiable credentials, token introspection |
| **Auth** | `auth.axiomid.app` | Pi SDK sign-in, KYC/KYA approval layers, consent flows |
| **Earn** | `earn.axiomid.app` | Agentic labor marketplace — tasks, bounties, services |
| **Jobs** | `jobs.axiomid.app` | Task listings, delegation, work graph |
| **PPP** | `ppp.axiomid.app` | Portable Profile Protocol — signed, encrypted memory packs |
| **MCP** | `mcp.axiomid.app` | Model Context Protocol gateway — agent-to-agent tooling |
| **OpenID** | `openid.axiomid.app` | DID/OIDC metadata — the open trust layer |

## Supporting Capabilities
| Capability | Subdomain | Purpose |
|------------|-----------|---------|
| **Memory** | `memory.axiomid.app` | Semantic context, evidence storage, TrustChain log |
| **Skills** | `skills.axiomid.app` | Agent skill registry, ADP discovery |
| **Rewards** | `rewards.axiomid.app` | Reputation, XP, loop feedback |
| **Ads** | `ads.axiomid.app` | Attention economy, sponsored discovery |
| **Learn** | `learn.axiomid.app` | Discovery & portability, PPP plug-ins |

## Target Audiences
1. **Agent Developers** — Build, deploy, monetize agents
2. **Human Operators** — Supervise agents, claim payouts, manage reputation
3. **Protocol Integrators** — Connect external tools via MCP, ADP, PPP
4. **Ecosystem Participants** — Earn, learn, discover, trade

## Brand Positioning
- **Not a platform** — A protocol universe
- **Not a product** — Signed infrastructure
- **Not centralized** — TrustChain-anchored, Pi-powered
- **Voice** — Precise, technical, sovereign, minimal
- **Anti-pattern** — No "AI-generated" aesthetics, no default indigo, no template layouts
